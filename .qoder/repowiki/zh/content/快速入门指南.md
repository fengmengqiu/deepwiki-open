## 简介

DeepWiki-Open 是一个开源的代码库文档生成工具，能够自动分析代码库并生成详细的维基文档。本指南将帮助新手用户在本地快速部署并运行 DeepWiki-Open，涵盖三种启动方式：使用 `run.sh` 脚本、Docker 容器化部署、以及手动启动前后端服务。

## 环境准备

在开始部署 DeepWiki-Open 之前，请确保您的系统已安装以下依赖：

- **Python 3.11+**：用于运行后端 API 服务。
- **Node.js 20+**：用于构建和运行前端应用。
- **Git**：用于克隆代码库。
- **Docker**（可选）：用于容器化部署。

### 安装步骤

1. 克隆 DeepWiki-Open 代码库：
   ```bash
   git clone https://github.com/AsyncFuncAI/deepwiki-open.git
   cd deepwiki-open
   ```

2. 安装 Python 依赖：
   ```bash
   pip install -r api/requirements.txt
   ```

3. 安装 Node.js 依赖：
   ```bash
   npm install
   ```

## 启动方式

DeepWiki-Open 提供了三种启动方式，您可以根据需求选择最适合的一种。

### 1. 使用 run.sh 脚本

`run.sh` 脚本是启动 DeepWiki-Open 的最简单方式。该脚本会自动启动后端 API 服务。

1. 确保您已安装 `uv` 工具：
   ```bash
   pip install uv
   ```

2. 运行 `run.sh` 脚本：
   ```bash
   ./run.sh
   ```

3. 后端服务将在 `http://localhost:8001` 上启动。

**Section sources**
- [run.sh](file://run.sh#L1-L1)

### 2. Docker 容器化部署

使用 Docker 可以轻松地在隔离环境中部署 DeepWiki-Open。

1. 构建 Docker 镜像：
   ```bash
   docker build -t deepwiki-open .
   ```

2. 运行 Docker 容器：
   ```bash
   docker run -p 3000:3000 -p 8001:8001 deepwiki-open
   ```

3. DeepWiki-Open 将在 `http://localhost:3000` 上启动。

**Section sources**
- [Dockerfile](file://Dockerfile#L1-L108)
- [docker-compose.yml](file://docker-compose.yml#L1-L30)

### 3. 手动启动前后端服务

如果您希望手动控制前后端服务的启动过程，可以分别启动后端和前端服务。

1. 启动后端服务：
   ```bash
   python -m api.main
   ```

2. 启动前端服务：
   ```bash
   npm run dev
   ```

3. 前端服务将在 `http://localhost:3000` 上启动，后端服务在 `http://localhost:8001` 上启动。

## 环境变量与API密钥配置

DeepWiki-Open 需要配置环境变量和 API 密钥才能正常运行。您可以通过创建 `.env` 文件来配置这些变量。

### 创建 .env 文件

在项目根目录下创建一个名为 `.env` 的文件，并添加以下内容：

```
PORT=8001
OPENAI_API_KEY=your_openai_api_key
GOOGLE_API_KEY=your_google_api_key
OLLAMA_HOST=http://localhost:11434
```

### API 密钥获取

- **OpenAI API 密钥**：访问 [OpenAI 官网](https://openai.com/) 注册账号并获取 API 密钥。
- **Google API 密钥**：访问 [Google Cloud Console](https://console.cloud.google.com/) 创建项目并启用 Google Generative AI API，然后获取 API 密钥。

## Ollama本地模型配置

DeepWiki-Open 支持通过 Ollama 使用本地 AI 模型，这使得您可以在不依赖云 API 的情况下运行 DeepWiki。

### 安装 Ollama

1. 访问 [Ollama 官网](https://ollama.com/) 下载并安装 Ollama。
2. 启动 Ollama 服务。

### 下载模型

打开终端并运行以下命令下载所需的模型：

```bash
ollama pull nomic-embed-text
ollama pull qwen3:1.7b
```

### 配置 DeepWiki 使用 Ollama

1. 创建 `.env` 文件并配置 Ollama 主机：
   ```
   OLLAMA_HOST=http://localhost:11434
   ```

2. 在前端界面中选择 "Use Local Ollama Model" 选项。

## 使用DeepWiki

### 访问前端界面

启动服务后，打开浏览器并访问 `http://localhost:3000`。

### 生成维基

1. 在输入框中输入代码库的 URL（如 GitHub、GitLab 或 Bitbucket 仓库 URL）。
2. 点击 "Generate Wiki" 按钮。
3. DeepWiki 将自动分析代码库并生成维基文档。

### 通过聊天窗口提问

1. 在维基页面中，找到聊天窗口。
2. 输入您的问题，DeepWiki 将根据代码库内容回答您的问题。

## 常见问题排查

### API密钥无效

- 确保您已正确配置 `.env` 文件中的 API 密钥。
- 检查 API 密钥是否已过期或被撤销。

### 端口冲突

- 如果端口 `8001` 或 `3000` 已被占用，请修改 `.env` 文件中的 `PORT` 变量。

### 模型加载失败

- 确保 Ollama 服务已启动。
- 检查模型是否已正确下载。

## 验证安装

完成部署后，您可以通过以下步骤验证安装是否成功：

1. 访问 `http://localhost:3000`。
2. 输入一个公开的 GitHub 仓库 URL（如 `https://github.com/AsyncFuncAI/deepwiki-open`）。
3. 点击 "Generate Wiki" 按钮。
4. 如果维基文档成功生成，则说明安装成功。
